Drop-in asset overrides. Everything is optional; missing files fall back to the built-in synthesized versions.

  assets/font.ttf                 UI font (a serif such as Cinzel or IM Fell English suits the mood)
  assets/sfx/<name>.wav|ogg       sound effects, names:
      slash knife fire explode slam zap chime bell hit die pickup levelup
      evolve roll hurt roar chest kindle death select clang arrow bullet
  assets/music/ambient.wav|ogg    exploration loop
  assets/music/boss.wav|ogg       boss loop

Audio files must be mono or stereo. Paths are relative to the folder you start the game from.
